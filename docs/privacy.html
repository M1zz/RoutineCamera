개인정보처리방침

세끼 (RoutineCamera) · 시행일: 2026년 10월 8일

세끼(RoutineCamera, 이하 "앱")는 이용자의 개인정보를 소중히 다루며, 관련 법령을 준수합니다. 본 방침은 앱이 어떤 정보를 수집하고 어떻게 이용·보관·파기하는지 설명합니다.

1. 수집하는 정보

항목내용
계정 식별자 별도의 회원가입이나 로그인은 없습니다. 기기가 iCloud에 로그인되어 있으면 Apple CloudKit이 이 앱 전용으로 발급하는 무작위 사용자 식별자를 친구 기능의 계정으로 씁니다. 이 식별자로는 이용자의 Apple 계정 이메일이나 이름을 알 수 없습니다.
프로필 친구 코드(무작위 6자리), 이용자가 입력한 "친구에게 보이는 이름"
기록 콘텐츠 식단·운동 사진(식전·식후), 메모, 기록한 날짜·시각·끼니. 기기 안에 저장되며, "내 식단 공유"가 켜져 있고 iCloud에 로그인되어 있으면 친구가 볼 수 있도록 앱의 CloudKit 공개 데이터베이스에 올라갑니다(사진은 긴 변 1024px로 줄여 올림). "내 식단 공유"는 처음에 켜져 있으며, 설정 > 계정 · 공유에서 끌 수 있습니다.
친구·그룹·응원 친구 요청과 친구 목록, 이용자가 만들거나 참여한 그룹의 이름과 멤버, 주고받은 응원 댓글·콕 찌르기 내용과 작성자 이름
알림 친구가 응원을 남기거나 기록을 올리면 Apple 푸시 알림(CloudKit 구독)으로 알려 드립니다. 식사 리마인드는 기기 안에서 예약되는 로컬 알림입니다.
앱에 보낸 의견 설정의 "피드백 보내기"로 직접 보낼 때만 전송됩니다. 고른 종류와 작성한 글, 앱 버전·iOS 버전·기기 종류·기기 언어 설정이 함께 가며, 이름·이메일은 답장을 위해 직접 적었을 때만 포함됩니다. 개발자의 답장은 앱 안에서 읽을 수 있습니다.
결제 정보 구독·코인 결제는 Apple(App Store)이 처리하며, 앱은 카드번호 등 결제 수단 정보를 수집하지 않습니다.
사진 분석: 기본 분석은 Apple Vision으로 기기 안에서 처리됩니다. 이용자가 설정에서 직접 OpenAI API 키를 등록하고 분석을 실행한 경우에만 해당 사진이 OpenAI로 전송되며, 이는 OpenAI의 개인정보처리방침을 따릅니다. 등록한 키는 기기 안에만 저장됩니다.
사진 보관함: "자동으로 사진앱에 저장"을 켜면 찍은 사진이 사진 앱의 '세끼식단'/'세끼운동' 앨범에도 저장됩니다.

2. 이용 목적

  • 식단·운동 기록 저장 및 표시
  • 친구·그룹 간 기록 공유, 응원·콕 찌르기 기능 제공
  • 식사 리마인드 및 응원·친구 기록 도착 알림 발송
  • 구독·코인 등 구매 기능 제공
  • 보내 주신 의견에 답하고 앱을 고치는 데 활용

3. 보관 및 파기

  • 기기에 저장된 기록은 앱을 삭제하면 함께 삭제됩니다.
  • 공유된 기록은 앱에서 그 날의 기록을 지우면 서버에서도 지워집니다.
  • 서버에 올라간 데이터는 회원 탈퇴 시 삭제됩니다 (앱 내 친구 화면 > 계정 설정 > 회원 탈퇴). 탈퇴하면 친구 코드와 이름, 올린 식단·운동 기록, 내가 남긴 응원, 친구 연결, 그룹 참여와 내가 만든 그룹, 알림 구독이 삭제되며 복구할 수 없습니다.
  • 잔여 데이터 삭제를 원하시면 아래 연락처로 요청해 주세요. 지체 없이 처리합니다.

4. 제3자 제공 및 처리 위탁

앱은 이용자의 개인정보를 판매하지 않으며, 광고나 제3자 분석 도구를 쓰지 않습니다. 서비스 제공을 위해 다음 서비스가 데이터를 처리합니다.

서비스용도
Apple iCloud (CloudKit)계정 식별, 공유 기록·친구·그룹·응원 저장, 앱에 보낸 의견 저장, 푸시 알림 배달
Apple App Store구독·인앱 결제 처리
OpenAI (선택)이용자가 직접 API 키를 등록한 경우에 한해 음식 사진 분석

5. 이용자의 권리

  • "내 식단 공유"는 언제든 설정에서 끌 수 있으며, 끄면 이후 기록은 업로드되지 않습니다.
  • 회원 탈퇴로 서버 데이터 삭제를 직접 실행할 수 있습니다.
  • 개인정보 열람·정정·삭제 요청은 아래 연락처로 문의해 주세요.

6. 아동의 개인정보

앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.

7. 방침의 변경

본 방침이 변경되는 경우 이 페이지를 통해 고지하며, 중요한 변경은 앱 내에서 별도로 안내합니다.
